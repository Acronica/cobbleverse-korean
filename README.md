# COBBLEVERSE 한글패치

Minecraft 모드팩 **COBBLEVERSE 1.7.42** (Cobblemon) 비공식 한국어 패치입니다.

| 파일 | 내용 | 설치 |
|---|---|---|
| `COBBLEVERSE-KoreanDialogue-v1.zip` | 관장·사천왕·챔피언·조직·일반 트레이너 대사 7,018줄 한국어 번역 (리소스팩) | 클라이언트 `resourcepacks` 폴더에 넣고 게임에서 켜기. 서버 접속 시 자동 다운로드도 지원 |
| `COBBLEVERSE-KoreanNames-v2.zip` | 트레이너 1,703명 이름표를 정식 한국어판 이름으로 변경 (데이터팩) | 서버(또는 싱글 월드)의 `datapacks` 폴더에 넣기. 플레이어는 설치 불필요 |

- 인물 이름은 포켓몬 정식 한국어판 표기(웅, 이슬, 난천…)를 따르고, 호연 지방의 이탈리아판 이름은 음차했습니다.
- 게임 언어를 **한국어**로 설정해야 적용됩니다.

Releases 페이지에서 최신 파일을 받으세요.
